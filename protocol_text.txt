Trabalho Prático 1 (Cinco Aulas) 
O objectivo deste trabalho é desenvolver um dispositivo de aquisição de dados utilizando a 
plataforma microcontrolada Microchip Explorer16/32 (com um PIC24FJ1024GB610).  
Deverá ter 3 canais analógicos e 6 canais digitais: 
• três entradas analógicas; 
• duas entradas digitais (RD6 e RD7); 
• três saídas digitais; e 
• um canal digital, que se pode configurar como entrada ou como saída (RA7). 
Adicionalmente deverá ter: 
• uma interface de comunicação série RS232 a 9600bits/s. 
Opcionalmente poderá apresentar dados no LCD da placa. 
Deverá ser possível: 
• configurar que entradas se pretende amostrar (monitorizar); 
• configurar a frequência de amostragem (será necessário incluir uma rotina de 
atendimento de interrupts associada a um timer para contar o tempo); 
• configurar o número de amostras, de cada entrada, a enviar em cada mensagem de 
monitorização (que envia valores de todas as entradas configuradas); e 
• criar/eliminar um canal virtual com dois bits (RD6 e RD7), que terá valores entre zero e três, 
o por exemplo: (11)2=(3)10 ; 
• configurar um evento de alerta associado ao canal virtual: sempre que o valor do canal virtual 
passe a ser igual a um valor configurável, deverá ser enviada uma mensagem de alerta. 
Para configurar, actuar e monitorizar o dispositivo, este será ligado a um computador através da 
linha série, utilizando um conversor RS232-USB. Serão trocadas mensagens JSON (JavaScript 
Object Notation). Cada grupo deverá definir o formato específico das mensagens de: 
• configuração; 
• monitorização; e 
• actuação (para colocar valores nas saídas digitais). 
 
Cada grupo poderá melhorar os requisitos propostos ou fazer a sua interpretação dos mesmos, 
sempre que estes não sejam explícitos ou completos. Melhorias serão valorizadas. Adicionalmente, 
cada grupo poderá implementar requisitos adicionais.

Relatório 
O relatório deverá: (1) apresentar funcionalidades/requisitos do dispositivo; (2) descrever o comportamento 
do dispositivo; (3) explicar por palavras próprias como configurar entradas e saídas digitais, ler entradas 
digitais, escrever saídas digitais, configurar a UART, enviar dados pela UART, receber dados pela UART, 
configurar o ADC, ler do ADC, e como configurar e usar o timer; (4) descrever os testes efectuados que 
mostram as funcionalidades do sistema; (5) apresentar conclusões; (6) colocar em anexo o código (não 
esquecer) e o datasheet. Não é necessário repetir no corpo do relatório informação que está no datasheet.

Mensagens JSON 
Como referido, cada grupo deve definir o formato específico das mensagens JSON. No entanto, aqui 
ficam alguns exemplos para simplificar a compreensão do que se pretende. 
 
Exemplos de mensagens a enviar do PC para o PIC (dispositivo de aquisição de dados): 
• Para configurar o porto bidirecional RA7 como saída: {“b”:0} 
• Para configurar RA7 como entrada: {“b”:1} 
• Para configurar os bits RD6 e RD7 como um único canal virtual de dois bits: {“v”:1} 
• Para configurar os bits RD6 e RD7 como dois canais independentes {“v”:0} 
• Para configurar que entradas se pretende amostrar: {“Ax”:1, “Ay”:0, “Az”:0, “D6”:0, 
“D7”:0, “DB”:1, “DV”:1} (neste caso uma entrada analógica e os canais digitais 
bidirecional e virtual eram as únicas entradas que se pretendiam amostrar) 
• Para configurar o período de amostragem: {“p”:1} (ler valores a cada 1 segundo e armazenar 
num array) 
• Para configurar o número de amostras, de cada entrada, a enviar em cada mensagem: {“n”:5} 
(5 amostras) 
• Para colocar numa determinada saída digital valor 1: {“Dw”:1} 
Exemplo de mensagem monitorização a enviar do PIC (dispositivo de aquisição de dados) para o PC 
com 5 amostras de uma entrada analógica e dos canais digitais bidirecional e virtual: 
• {‘Ax’:[512,514,516,516,510], ‘DB’: [0,0,1,1,1], ‘DV’: [0,1,2,3,3]}
